# FTX-1 Пульт — удалённое управление Yaesu FTX-1

Полноценный пульт для FTX-1 (Field и Optima) через USB-кабель трансивера:
CAT-управление, звук приёма в колонки ПК/телефона, передача с микрофона ПК/телефона,
водопад, все регуляторы и всё меню EX трансивера.

```
 FTX-1 ──USB──► ПК с Windows (сервер: CAT + USB-звук) ──Wi-Fi/LAN/VPN──► браузер
                 │                                                    ├─ этот же ПК
                 └ http://localhost:8080                              ├─ другой ПК (Windows)
                                                                      └─ Android (ставится как приложение)
```

## Что умеет

* Частота VFO-A/B: круглая ручка-валкодер (вращение по кругу, 100 делений на оборот, инерция), цифры (колесо или клик по разряду),
  кнопки ±, стрелки клавиатуры, ввод с клавиатуры (`7.074`, `14200`, `145500000`).
* Диапазоны 160 м … 70 см с памятью последней частоты и вида работы; все виды работы.
* Шкалы: S-метр, при передаче — PO, SWR, ALC.
* Водопад + спектр с обзором «Авто» (по реальной полосе звука трансивера: в SSB ~3,5 кГц, в FM ~9 кГц) или 3–24 кГц, полоса фильтра, IF SHIFT, режектор, тон CW;
  двойной клик (двойной тап) — настроиться на сигнал.
* Шумодав пульта (только в FM): по шумоподавителю трансивера (SQL, команда RI) или по уровню; глушение «хвоста» после передачи — во всех видах работы.
* На мониторе любого размера пульт и панель помещаются в окно целиком, без прокрутки страницы (масштаб авто или вручную); на телефоне — прокручиваемая колонка.
* Приём: AF, RF, SQL, AGC, IPO/AMP1/AMP2, ATT, NB, DNR, DNF, ручной режектор, CONTOUR, APF,
  WIDTH, IF SHIFT, NAR, CLAR (RIT/XIT), двойной приём.
* Передача: мощность, MIC GAIN, PROC, AMC, VOX, монитор, CTCSS/DCS, сдвиг репитера, TXW,
  тюнер (встроенный SPA-1, внешний FC-40, ATAS).
* VFO/память: A→B, B→A, A⇄B, SPLIT, MAIN/SUB, скан, каналы памяти, QMB, LOCK, «мои частоты».
* CW: скорость, тон, ключ, BREAK-IN, 5 ячеек памяти ключа (пишутся в трансивер и передаются им самим).
* **Меню EX целиком** — 402 пункта с поиском, чтением и записью.
* Консоль CAT для любых команд.
* Защита: передача снимается, если пропала связь с клиентом больше 1,5 с или превышено
  `max_tx_seconds`; одновременно передавать может только один клиент.

## Важно про водопад

FTX-1 **не передаёт картинку своей панорамы по CAT** — команда `SS` только меняет настройки
панорамы на экране трансивера. Поэтому водопад в пульте строится из звука с USB-кодека:
это полоса приёмника (до 24 кГц в зависимости от фильтра, на SSB полезно ~3–4 кГц), а не
широкая панорама диапазона, как на экране трансивера. Для FT8/CW/SSB этого хватает,
широкий обзор диапазона без дополнительного SDR-приёмника на этом трансивере невозможен.

## Установка (Windows)

Сначала установите драйвер **Virtual COM Port (CP210x)** с сайта Yaesu и подключите FTX-1 кабелем USB.
В «Диспетчере устройств» появятся *Enhanced COM Port*, *Standard COM Port* и звук *USB Audio CODEC*.

**Вариант А — готовый FTX1-Pult.exe** (Python не нужен): скачайте его со страницы
[Releases → latest](https://github.com/Evgeny161rus/ftx1-pult/releases/tag/latest) и запускайте двойным кликом.
Каждое изменение в ветке `main` пересобирает exe автоматически (GitHub Actions); собрать вручную — `build_exe.bat`.

**Вариант Б — без сборки.** Установите Python 3.10+ с python.org (галочка *Add python.exe to PATH*)
и запустите двойным кликом `FTX1-Pult.pyw`. При первом запуске программа сама предложит
установить нужные библиотеки.

### Окно «Панель управления»

При запуске открывается окно сервера (без консоли), а в трее появляется значок:

* **Трансивер** — COM-порт, скорость, звук приёма и передачи (отдельно) и способ PTT. Кнопка «Найти» подбирает FTX-1 сама
  (Enhanced-порт для CAT, Standard — для PTT, USB Audio CODEC — для звука).
* **▶ Запустить / ■ Остановить** — связь с трансивером; лампа показывает «на связи / не отвечает / ПЕРЕДАЧА»,
  рядом — частота и вид работы.
* **Открыть пульт** — пульт на этом ПК.
* **Телефон и другие ПК** — пароль, адреса и **QR-код**: наведите камеру телефона.
* **Запуск** — автозапуск вместе с Windows (в трее, без окна), сразу подключаться к трансиверу,
  открывать пульт при запуске, ограничение длительности передачи.
* **Подключены** — кто сейчас работает с пультом и кто передаёт; **Журнал** событий.
* **Выйти из программы** — полностью остановить сервер. Если окно просто закрыть, сервер
  продолжит работать в трее; повторный запуск программы откроет это же окно.

Настройки сохраняются сразу, вручную править `config.json` не нужно. Режим симулятора
(галочка в карточке «Трансивер») позволяет проверить всё без трансивера.

### Настройка трансивера для связи через микрофон ПК

В меню трансивера (вкладка «Меню» в пульте → кнопка «Показать эти пункты»):

| Пункт | Что задаёт |
|---|---|
| `SSB_MOD_SOURCE`, `AM_MOD_SOURCE`, `FM_MOD_SOURCE`, `DATA_…` | источник модуляции — выберите USB (номер значения сверьте с инструкцией FTX-1) |
| `…_USB_MOD_GAIN` | уровень звука с ПК в передатчик |
| `…_USB_OUT_LEVEL` | уровень приёма, уходящий в ПК |

Уровень подбирайте по шкале ALC: при нормальной речи ALC в начале зоны, без «зашкала».
Скорость CAT в меню трансивера должна совпадать со скоростью в панели (по умолчанию 38400).

## Телефон Android (и другие ПК)

1. Телефон в той же сети Wi-Fi, что и ПК с трансивером.
2. Наведите камеру на QR-код в панели управления (или откройте в Chrome адрес `https://192.168.x.x:8443`).
3. Сертификат самоподписанный: «Дополнительные» → «Перейти на сайт». HTTPS обязателен —
   без него браузер не даёт доступ к микрофону.
4. Введите пароль, заданный в панели управления.
5. Меню Chrome → **«Установить приложение»** — появится значок «FTX-1» как у обычного приложения.

Работа через интернет: не открывайте порт на роутере наружу, используйте VPN
(WireGuard, ZeroTier, Tailscale и т.п.) и адрес ПК внутри VPN. В настройках пульта
для мобильного интернета выберите качество звука 8 кГц.
На самом ПК с трансивером пульт по умолчанию работает в режиме 48 кГц — звук идёт без пересчёта частоты.

## config.json (для опытных — всё это настраивается в панели)

| Ключ | По умолчанию | Описание |
|---|---|---|
| `cat_port` | `""` | Enhanced COM-порт FTX-1 |
| `cat_baud` | `38400` | скорость CAT (как в меню трансивера) |
| `ptt_method` | `TX1` | `TX1` — PTT командой CAT; `TX2` — альтернативная команда (DATA); `RTS` — линией RTS/DTR |
| `ptt_port`, `ptt_line` | `""`, `RTS` | для `ptt_method: RTS` — Standard COM-порт и линия (RTS/DTR), см. пункт меню `…_RPTT_SELECT` |
| `audio_in_name`, `audio_out_name` | `""` | вход (приём) и выход (передача) звука трансивера; пусто — подбор автоматически (USB Audio CODEC / USB Audio Device) |
| `audio_in_index`, `audio_out_index` | `null` | номера устройств (обычно не нужны — устройство выбирается в панели) |
| `http_port` | `8080` | пульт на самом ПК (`http://localhost:8080`) |
| `https_port` | `8443` | пульт для телефона и других ПК |
| `password` | `""` | пароль для входа не с этого ПК; пусто — удалённый доступ запрещён |
| `max_tx_seconds` | `180` | максимальная длительность одной передачи |
| `auto_connect` | `true` | сразу подключаться к трансиверу при запуске |
| `open_panel`, `open_pult` | `true`, `false` | что открывать при запуске |
| `simulate` | `false` | симулятор вместо трансивера |
| `audio_api` | `""` | предпочитаемый звуковой API (MME/WASAPI) |

## Если что-то не так

* **«Порт не открывается»** — порт занят другой программой (WSJT-X, логгер): закройте её или настройте её на работу через flrig/rigctld.
* **«Трансивер не отвечает»** — не тот COM-порт (нужен Enhanced) или не совпадает скорость CAT.
* Подробности ошибок — в журнале панели и в файле `ftx1-pult.log` рядом с программой.
* **Нет звука приёма / пустой водопад** — в панели управления выберите вход «Микрофон (… USB Audio …)» и выход
  «Динамики (… USB Audio …)» трансивера (Windows может называть его *USB Audio CODEC* или *USB Audio Device*);
  в пульте нажмите «🔇 Звук»; проверьте `…_USB_OUT_LEVEL`. В FM при закрытом шумоподавителе водопад тёмный — это нормально.
* **Передача есть, модуляции нет** — `…_MOD_SOURCE` не USB для текущего вида работы
  или мал `…_USB_MOD_GAIN`.
* **PTT не включает передачу** — попробуйте `"ptt_method": "TX2"` или способ `RTS` через Standard-порт.
* **Эхо/свист на телефоне** — включите «Глушить приём во время передачи» и эхоподавление,
  используйте гарнитуру.

## Устройство программы

* `server/cat.py` — протокол CAT FTX-1: очередь команд, опрос, разбор ответов, Auto Information.
  Форматы команд сверены с CAT Operation Reference Manual 2508-C (по драйверу Hamlib для FTX-1).
* `server/audio.py` — USB-звук 48 кГц, передискретизация 16/8 кГц, БПФ для водопада, джиттер-буфер TX.
* `server/webserver.py` — HTTP/HTTPS + WebSocket без внешних библиотек.
* `server/sim.py` — симулятор трансивера и эфира.
* `server/main.py` — сервер, панель управления, автозапуск, значок в трее.
* `FTX1-Pult.pyw` — запуск двойным кликом без консоли.
* `server/menu_ftx1.json` — таблица меню EX (402 пункта).
* `web/` — пульт (HTML/JS, ставится как PWA) и `panel.html` — окно управления сервером.

Отдельные калибровки шкал (PO, SWR, ALC) и таблицы полос WIDTH ориентировочные — уточняются
на реальном трансивере. Проверено на симуляторе; на живом FTX-1 первым делом проверьте PTT
и источник модуляции на эквиваленте нагрузки.
