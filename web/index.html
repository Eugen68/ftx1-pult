Включите декодер и настройтесь на телетайп. Метеосводки DWD (Германия): 50 Бод, сдвиг 450 Гц — выберите станцию в списке справа. Любительский RTTY: 45,45 Бод / 170 Гц, около 14080–14090 кГц.
Перевод

Передача — звуком через USB (AFSK), трансивер должен быть в режиме DATA-L или DATA-U. Тоны ставятся по любительскому стандарту (mark — верхняя частота в эфире); если корреспондент не читает — .

Наклон0 —
Метеофакс принимается в USB на 1,9 кГц ниже частоты станции (выберите станцию в списке — частота и вид работы поставятся сами). Полоса WIDTH — не уже 2,4 кГц: сигнал занимает 1500–2300 Гц. Картинка начнётся сама по тону старта. Клик по картинке — указать, где левый край карты; ◀ ▶ — исправить наклон.
Для связи через микрофон ПК в меню трансивера для нужных видов работы (SSB / AM / FM / DATA) параметр …_MOD_SOURCE должен указывать на USB, а …_USB_MOD_GAIN задаёт уровень звука с ПК. …_USB_OUT_LEVEL — громкость приёма, идущая в ПК. Номера значений сверьте со страницей «MOD SOURCE» в инструкции FTX-1.
